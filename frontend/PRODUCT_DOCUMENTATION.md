# AI-Assisted Investigation Documentation System
## Product Documentation — POC Version

**Client:** Anti-Corruption Bureau (ACB), Government of Telangana  
**Version:** 1.0.0 (POC)  
**Tech Stack:** Next.js 14, TypeScript, Tailwind CSS, Recharts, jsPDF  
**URL (Dev):** http://localhost:3001  

---

## Quick Start

```bash
cd frontend
npm install
npm run dev
# Opens at http://localhost:3001
```

| Role | Email | Password |
|------|-------|----------|

## Full Demo Workflow

```
Login → Dashboard → Create Case → Upload Documents
     → AI Extraction → Generate Draft → Review & Edit → Export PDF
```

## Data Architecture (No Database)

All data stored in `/data/` directory as JSON files:

| File | Contents |
|------|----------|
| `cases.json` | All investigation cases |
| `documents.json` | Uploaded file metadata |
| `extractions.json` | AI extraction results |
| `drafts.json` | Generated draft documents |
| `logs.json` | Activity log entries |

**Seed Data:** 5 pre-loaded cases covering Bribery, Corruption, Fraud, Misappropriation, Abuse of Power.

**DB Migration Path:** Replace functions in `lib/store.ts` with PostgreSQL queries (Prisma or pg). Interface stays identical — no page/API changes needed.

## AI Features

| Feature | How It Works |
|---------|-------------|
| OCR Extraction | Calls `lib/ai-service.ts → performOCRExtraction()` |
| Draft Generation | Calls `lib/ai-service.ts → generateDraft()` |
| Default (no key) | Returns realistic mock data with 2s simulated delay |
| With OpenAI key | Uses GPT-4o for drafts, GPT-4o-mini for extraction |

**To enable real AI:**  
Copy `.env.local.example` → `.env.local`  
Add: `OPENAI_API_KEY=sk-your-key-here`

**Mock extraction returns:**
- Accused name, department, bribe amount, location
- Key dates, officer names, witness names
- 94% confidence score

**Mock drafts include:**
- Full FIR with all legal sections (PC Act 1988, Sections 7, 13(1)(d))
- Proper government letterhead format
- Panchanama references, witness statements, seizure memos

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/auth/login` | Authenticate user |
| POST | `/api/auth/logout` | Clear session cookie |
| GET | `/api/cases` | List all cases |
| POST | `/api/cases` | Create new case |
| GET | `/api/cases/[id]` | Get single case |
| PATCH | `/api/cases/[id]` | Update case |
| GET | `/api/documents?caseId=` | Get documents for case |
| POST | `/api/documents` | Upload document (multipart) |
| GET | `/api/extract?caseId=` | Get extraction for case |
| POST | `/api/extract` | Run AI extraction |
| PATCH | `/api/extract` | Update extraction fields |
| GET | `/api/draft?caseId=` | Get drafts for case |
| POST | `/api/draft` | Generate AI draft |
| PATCH | `/api/draft/[id]` | Update draft content/status |
| POST | `/api/draft/[id]/comment` | Add review comment |
| POST | `/api/export` | Log PDF export |
| GET | `/api/dashboard` | Dashboard statistics |
| GET | `/api/logs` | Activity logs |
